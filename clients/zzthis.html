What it is

zzThis is a code people can write by hand: a few plain words between zz markers, such as zz-copper-lantern-sky-zz. A phone camera reads it and opens the record linked to it: a page, a file, a form, or a zzPage.

It works alongside barcodes and QR codes, for logistics, inventory, postal and everyday use, where a printer or label is not at hand. zzThat is the free consumer app built on it.

Zero State lists zzThis as client work. zzThis is Michael Chung's invention and IP, not a Zero State product.

Visit zzthis.com ↗

In short

Write the code on tape, a box or a sign; scan it with the zzThat app; open what it links to. The reader ignores case, accepts hyphens or spaces, and asks rather than guesses when a word is unclear.

zzThis is Michael Chung's invention, patent pending; zer0state builds it: a shared grammar library, an API on Cloudflare Workers, and iOS, Android and web clients. Handwriting accuracy is being measured on a real-photo test set; it is not yet a published result.
