Neon Genie

Governed opportunity and product intelligence — turn weak signals into evidence-bound, testable packets without inventing facts.

v3.23.0 · advisory only · fail-closed

What it is

Neon Genie is a Hermes skill for product coherence audits, Wayfinder-ready handoffs, opportunity mining, zero-capital first-cash loops, commercial model mapping, and evidence-gap analysis.

Claims are labeled OBSERVED, INFERRED, SPECULATIVE, or NOT_COMPUTABLE. Public facts are researched; private facts become DataRequests. Never invent. Advisory only — may draft and recommend; may not spend, publish, contact, or mutate repos.

How it fits

It is not Kubrick (cinematic) and not an unconstrained idea generator. It fails closed when proof, buyer, or access is missing.

Install

Hermes skill. Prefer Skills Hub when available; clone install is always supported.

# Hermes Skills Hub (when wired to this org path):
# hermes skills install Zero-State-LLC/NeonGenie

git clone https://github.com/Zero-State-LLC/NeonGenie.git
cd NeonGenie
./install.sh
python ~/.hermes/skills/neon-genie/scripts/neon_genie.py do doctor
