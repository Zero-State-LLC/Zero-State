Sigil-Forge

Corpus methods forge the glyph. The end product is the wallpaper — atmosphere, geometry, and an encrypted vault of intent and method provenance sealed into the PNG.

v0.13.0 · offline CLI · SF12 vault · skill name: sigil-forge

What it is

Sigil-Forge is a Hermes skill that encodes a statement of intent into a layered sigil image. Spare monogram, kamea paths, Rose Cross, bind-runes, and optional planetary plates build immutable glyph geometry. The handoff object is the wallpaper PNG, with intent, methods, digests, and Proof-of-Intent surfaces sealed in an SF12 LSB vault.

Packets and capsules remain operator workspace. Public pixels stay free of plaintext intent; opening the vault requires a passphrase. Methods are craft and steganographic layering — not efficacy claims, and not Goetic/Enochian authority seals in the default forge.

How it fits

Installable offline-first skill for Hermes agents and operators. Wizard step runner for guided intake; expert construct for craft flags; wallpaper as product with open --wallpaper.

Install

Hermes skill. Prefer Skills Hub when available; clone install is always supported.

# Hermes Skills Hub (when wired to this org path):
# hermes skills install Zero-State-LLC/Sigil-Forge

git clone https://github.com/Zero-State-LLC/Sigil-Forge.git
cd Sigil-Forge
bash install.sh
# → ~/.hermes/skills/sigil-forge

export SIGIL_FORGE_PASSPHRASE='…'
python3 scripts/sigil_forge.py construct \
  --intent "I maintain calm focus" \
  --wallpaper --surface phone_lock --embed vault
python3 scripts/sigil_forge.py open --wallpaper \
  out/sigil-forge/*/wallpaper/phone-lock.png --json
