Hyperlex

Catch language while it is still becoming culture — a cultural radar for slang with settled forecasts only.

v0.4.0 · offline-first · Brier requires settlement

What it is

Hyperlex watches how new phrases leak out of chats, forums, and meme stacks — half joke, half signal — and asks practical questions: what showed up, which slang family it belongs to, how hard it is spreading, and whether it is starting to make itself real.

It runs as a Hermes skill: offline-friendly by default, receipt-backed when you care, and stubborn about one rule — no fake accuracy. Brier scores only appear after a human settles an outcome. Simulation stays labeled research.

How it fits

Cool without the con: less AI vibe report, more flight recorder for memetic weather.

Install

Hermes skill. Offline demo first; no API keys required for the mock route.

git clone https://github.com/Zero-State-LLC/Hyperlex.git
cd Hyperlex
bash install.sh --dry-run && bash install.sh
python3 scripts/hyperlex.py demo
